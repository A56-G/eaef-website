# EAEF Website

الموقع الرسمي لـ **مصنع الشرقية لسحب الألمنيوم** (Eastern Aluminum Extrusion Factory) — الدمام، المملكة العربية السعودية.

صفحة واحدة ثنائية اللغة (English / العربية مع RTL)، مبنية بـ [Vite](https://vitejs.dev) و GSAP و Lenis، وكل الصور حقيقية من المصنع.

## التشغيل

```bash
npm install
npm run dev       # سيرفر تطوير على http://localhost:5173
npm run build     # نسخة الإنتاج في dist/
npm run preview   # معاينة نسخة الإنتاج
```

## الهيكل

```
index.html            محتوى الصفحة (النص الإنجليزي)
src/main.js           الحركة، تبديل اللغة، النماذج
src/i18n/ar.js        النصوص العربية (مربوطة بـ data-i18n)
src/styles/main.css   التصميم
public/img/           الصور والشعار
```

### إضافة أو تعديل نص
1. في `index.html` حط على العنصر `data-i18n="key"` والنص الإنجليزي.
2. في `src/i18n/ar.js` أضف نفس `key` بالترجمة العربية.

اللغة الافتراضية بتتحدد من لغة المتصفح، واختيار الزائر بيتحفظ.
