# EAEF Website

الموقع الرسمي للشركة — قطاعات الألومنيوم.

## الهيكل

```
index.html          الصفحة الرئيسية (عربي RTL)
assets/css/         ملفات التنسيق
assets/js/          السكربتات
assets/images/      الصور والشعار
```

## التشغيل محلياً

افتح `index.html` في المتصفح، أو شغّل سيرفر بسيط:

```bash
python3 -m http.server 8000
```

## النشر

يمكن نشره مجاناً على GitHub Pages من إعدادات الريبو: Settings → Pages → Branch: `main`.
